# Catatan hukum

Repo ini dibuat untuk eksperimen teknis dengan **konten yang Anda miliki secara sah**.

## Yang boleh

- Mempelajari dan menjalankan recompiler open-source.
- Memakai salinan game yang Anda beli/ikuasai secara legal, untuk pemakaian sendiri.
- Menyimpan hasil build di perangkat Anda sendiri.

## Yang tidak boleh

- Mengunggah ISO/ROM/XBE/XEX, asset, atau binary game ke repo ini.
- Membagikan APK hasil recompile dari game komersial.
- Memakai repo ini untuk menghindari DRM atau pembatasan lisensi.
- Mengklaim kode/asset game orang lain sebagai milik Anda.

## Penafian

Recompile game komersial dapat melanggar EULA, DMCA, atau hukum setempat tergantung yurisdiksi. Repo ini tidak memberikan nasihat hukum. Tanggung jawab sepenuhnya ada pada pengguna. Jika ragu, pakai judul open-source/homebrew Xbox sebagai target.
